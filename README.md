# workout-app — 주 4회 2분할 운동 기록

개인용 운동 기록 웹앱. 단일 `index.html`(빌드 없음, 외부 라이브러리 없음), 모바일 화면 기준.

**라이브: https://nisloke.github.io/workout-app/** (`main` push = 배포)

## 기능

- **세션 A**(밀기+하체 전면, 월·목) / **B**(당기기+하체 후면, 화·금) — 요일로 자동 제안, 탭으로 전환
- 슬롯마다 **종목 드롭다운**으로 교체. 기록은 슬롯·종목 조합별로 따로 쌓인다(백스쿼트와 핵스쿼트가 한 칸에 섞이지 않게)
- 종목당 **무게(kg/lb)·횟수(마지막 세트)·메모** 1칸씩 + 세트 체크박스(램프 포함). 입력 즉시 자동 저장, 직전 기록으로 자동 채움
- **증량/감량 자동 판정** ▲▼ — 더블 프로그레션 규칙을 기록으로 기계 판정(상한 도달 시 증량, 증량 후 하한 미달 시 복귀, 3세션 정체 시 10% 감량)
- 종목 **ⓘ 팝업** — 수행 방법·추천 사유·주의사항·시연 쇼츠
- **초 단위 수행 대본** — ① 집 모빌리티 8:00 · ② 유산소 워밍업 5:00 · ④ 유산소 본절 14:00 (각 단계 시간의 합 = 블록 시간)
- **기록 화면** — 운동 점수(무게 kg 환산 × 마지막 세트 횟수 합)·체중·수면 차트, 날짜별 세부 기록 카드(행 단위 편집·삭제)
- 다크/라이트 토글(기본은 시스템 설정), 뒤로가기로 팝업·기록 화면 닫기

## 저장

- **Google 로그인 시 Firebase Firestore 자동 동기화** — 입력 1.5초 뒤 푸시, 기기 간 충돌은 최신 저장(`savedAt`) 우선. 로그인 가능 계정은 Firestore 보안 규칙의 이메일 화이트리스트로 제한된다
- **미로그인·오프라인·동기화 실패 시에도 localStorage에 항상 저장**된다(브라우저 데이터 정리 시 유실 가능)
- **JSON 내보내기/불러오기** 지원
- 콘솔 설정·보안 규칙 절차는 [`firebase-setup.md`](firebase-setup.md)
